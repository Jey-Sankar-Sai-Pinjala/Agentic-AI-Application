# Sample Files

This directory contains sample files for testing the Agentic AI Application.

## Files

- `sample_code.py`: Sample Python code for testing code explanation feature
- `sample_text.txt`: Sample text for testing summarization and sentiment analysis

## Usage

1. **Code Explanation Test**:
   - Upload `sample_code.py` or paste its content
   - Ask: "Explain this code" or "What does this code do?"

2. **Summarization Test**:
   - Upload `sample_text.txt` or paste its content
   - Ask: "Summarize this" or "Give me a summary"

3. **Sentiment Analysis Test**:
   - Use `sample_text.txt` or any text
   - Ask: "Analyze the sentiment" or "What's the sentiment?"

## Additional Test Cases

### Audio Transcription + Summary
- Upload an audio file (MP3/WAV/M4A)
- Ask: "Transcribe and summarize this audio"

### PDF Text Extraction
- Upload a PDF file
- Ask: "Extract text from this PDF"

### Image OCR
- Upload an image with text (JPG/PNG)
- Ask: "Extract text from this image"

### YouTube Transcript
- Paste a YouTube URL
- Ask: "Get the transcript" or "Summarize this video"
